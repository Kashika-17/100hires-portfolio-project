# 100Hires Portfolio Project

## Overview

This repository documents the completion of the first stage of the 100Hires hiring process.

The objective of this project was to set up an AI-assisted development environment using Cursor IDE, Claude Code, Codex, Git, and GitHub, while documenting the process and any challenges encountered.

## Tools Installed

- Cursor IDE
- Claude Code Extension (Anthropic)
- Codex Extension (OpenAI)
- Git for Windows
- GitHub

## Steps Completed

1. Installed Cursor IDE.
2. Installed the Claude Code extension.
3. Installed the Codex extension.
4. Created a public GitHub repository.
5. Installed Git for Windows.
6. Initialized a local Git repository.
7. Connected the local repository to GitHub.

## Challenges Encountered

### Git was not recognized

When attempting to initialize the repository, the terminal displayed:

> `'git' is not recognized as the name of a cmdlet...`

#### Resolution

- Installed Git for Windows.
- Restarted Cursor.
- Verified the installation using:

```
git --version
```

After installation, Git worked successfully.
